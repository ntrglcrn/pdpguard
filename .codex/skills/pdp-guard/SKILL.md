# PDP Guard

PDP Guard is a deterministic, evidence-first ecommerce quality platform with a
PDP-first specialization. AI may explain or group confirmed evidence; it does
not replace the deterministic rule engine.

Read [the current snapshot](../../project-context.md). The primary workflow is
Store → Catalog Discovery → PDP Inventory → Store Audit → Issues → Monitoring.
Specific PDP URL auditing is secondary Quick Audit.

`docs/prd/pdp-guard-v2.md` and `docs/roadmap.md` are the higher-priority source
of truth for product direction. This skill is fast orientation, not a replacement
for them. Read the full PRD/roadmap only when scope, priority, or milestone
decisions depend on them.

- For cross-cutting, engine, persistence, or security work, read
  [architecture.md](references/architecture.md).
- For task classification, proportional verification, or subagent selection,
  read [development.md](references/development.md).
- For frontend work, read `docs/design-system.md` separately.
